# M-001 角色资产包

这是用于生图、生视频和后期合成的男性角色身份资产包。

## 使用优先级

1. `identity/face-anchor-approved.png`：用户确认的六角度面部身份锚点，唯一优先提交。
2. `identity/face-id-board.jpg`：真实照片面部板，用于校验和补充脸部细节。
3. `identity/face-anchor-generated.png`：旧版AI示意图，不再作为主参考。
3. `identity/body-three-view-generated.png`：正面/左侧/背面三视图，只锁定身材和发型轮廓，不作为脸部依据。
4. `identity/front-neutral.jpg` + `identity/three-quarter-left.jpg`：辅助锁定正脸和立体结构。
5. `identity/left-profile.jpg` + `identity/front-original.jpg`：补充侧脸、发际线和自然状态。
6. `motion/action-reference.mp4`：只作为表情、手势和动作参考，不作为换脸参考。
7. `wardrobe/`：服装参考；每次只提交当前需要的一套，避免模型在一次任务里重绘多套服装。

## 固定身份

- 成年中国男性，178 cm，约72 kg
- 匀称偏健身体型
- 黑色短发，顶部自然纹理，两侧较短
- 浓直眉、深色眼睛、直鼻、清晰下颌线
- 自然偏暖浅中等肤色，干净无胡须
- 脸型、五官比例、发际线和年龄感不可改变

## 推荐提交方式

生图：真实照片面部板 + 当前单套服装图；三视图只在需要校准身体比例时附加。

生视频：真实照片面部板 + 三视图（仅体型参考）+ 当前单套定妆图 + 动作参考视频（如需要）。明确写明“脸部不可重绘，只改变动作、服装和场景”。

分镜：先完成单套定妆图，再把老虎机、字幕、闪光和取景框后期合成；不要让模型一次生成六格不同造型。

## 服装参考说明

`wardrobe/` 中的图片仅供款式和配色参考，含原始商品图中的水印/二维码区域，不应直接用于成片发布。
