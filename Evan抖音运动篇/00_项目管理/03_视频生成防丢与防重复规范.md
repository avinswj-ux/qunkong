# Seedance 视频生成防丢与防重复规范

适用模型：AP Seedance-2.0 标准版

## 强制规则

1. 同一时间只允许存在一个未结束的生成任务。
2. 每个镜头只点击或提交一次；提交后立即停止所有重复操作。
3. 提交成功后必须立刻记录：镜头号、提交时间、模型、提示词版本、任务 ID、起始图和目标时长。
4. 页面超时、无响应或刷新后，只查询已有任务 ID，不重新提交。
5. 只有明确返回失败且原任务不可恢复时，才建立新的重试任务；新任务必须使用 `-R1`、`-R2` 后缀。
6. 生成成功后，先下载到项目目录，再记录远端 URL、文件大小、时长和 SHA-256。
7. 本地文件能够正常播放并完成校验后，才能开始下一个镜头。
8. 禁止并行批量生成；禁止浏览器重复点击；禁止因等待时间长而自动重试。

## 文件命名

`SH01_opening_slotmachine_S20_STD_V001.mp4`

- `SH01`：镜头号
- `S20_STD`：Seedance-2.0 标准版
- `V001`：首次提交
- 重试：`V001-R1`、`V001-R2`

## 单任务状态机

`DRAFT → SUBMITTED → RUNNING → SUCCEEDED → DOWNLOADED → VERIFIED`

异常时：

`SUBMITTED/RUNNING → 查询原任务 → FAILED（确认失败后）→ RETRY_APPROVED → 新任务`

## 完成判定

- 已记录任务 ID 或上游唯一标识。
- MP4 已保存到 `05_镜头素材/SHxx/`。
- 文件大小大于 0。
- 能读取视频编码、分辨率、帧率和时长。
- 已记录 SHA-256。
- 画面人工检查后标记为“可用”或“退回”。
